# YI Camera Modern

Versión modificada de la aplicación **YI Camera** para mejorar su compatibilidad con dispositivos Android actuales.

Modified version of the **YI Camera** application to improve compatibility with modern Android devices.

---

## 🇪🇸 Español

### 🔧 Cambios

* Actualización del **Android SDK** para permitir instalar y ejecutar la aplicación en versiones modernas de Android.
* Se mantiene la funcionalidad original de la aplicación.
* No se han realizado cambios importantes en el funcionamiento de la cámara.

### ⚠️ Permisos

Debido a la antigüedad de la aplicación original, algunos permisos pueden **no solicitarse automáticamente** en versiones modernas de Android.

Si la aplicación no puede conectarse a la cámara o alguna función no funciona correctamente, debes conceder los permisos manualmente desde:

**Ajustes → Aplicaciones → YI Camera → Permisos**

Concede los permisos disponibles que necesite la aplicación.

### 📱 Compatibilidad

Esta modificación está destinada principalmente a solucionar problemas de compatibilidad con versiones modernas de Android.

La compatibilidad puede variar dependiendo del dispositivo Android y del modelo de cámara YI.

## 🇬🇧 English

### 🔧 Changes

* Updated the **Android SDK** to allow the application to be installed and run on modern Android versions.
* The original application functionality has been preserved.
* No major changes have been made to the camera's original functionality.

### ⚠️ Permissions

Due to the age of the original application, some permissions may **not be requested automatically** on modern Android versions.

If the application cannot connect to the camera or some features do not work correctly, you may need to manually grant the required permissions from:

**Settings → Apps → YI Camera → Permissions**

Grant any available permissions required by the application.

### 📱 Compatibility

This modification is primarily intended to solve compatibility issues with modern Android versions.

Compatibility may vary depending on the Android device and YI camera model.
