# YI Camera Modern

Versión modificada de la aplicación **YI Camera** para mejorar su compatibilidad con dispositivos Android actuales.

## 🔧 Cambios

* Actualización del **Android SDK** para permitir instalar y ejecutar la aplicación en versiones modernas de Android.
* Mantiene la funcionalidad original de la aplicación.

## ⚠️ Permisos

Debido a la antigüedad de la aplicación original, **algunos permisos pueden no solicitarse automáticamente** en versiones modernas de Android.

Si la aplicación no puede conectarse a la cámara o alguna función no funciona correctamente, es necesario conceder los permisos **manualmente** desde:

**Ajustes → Aplicaciones → YI Camera → Permisos**

Concede los permisos disponibles que solicite la aplicación.

## 📱 Compatibilidad

Probado principalmente para solucionar problemas de compatibilidad con versiones modernas de Android.

La compatibilidad puede variar dependiendo del dispositivo Android y del modelo de cámara YI.
